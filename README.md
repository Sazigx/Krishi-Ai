Krishi AI 🌿
Intelligent Farm Management for Modern Nepal

Krishi AI is a full-stack, AI-powered Progressive Web Application (PWA) designed to modernize agricultural practices. By combining the multimodal capabilities of Google's Gemini 2.0 Flash model with real-time environmental data, Krishi AI provides farmers with instant crop disease diagnostics, organic farming guides, and live market trends.

Core Technologies:

Backend: Python, FastAPI, Google GenAI SDK

Frontend: HTML5, CSS3 (Glassmorphism), Vanilla JavaScript

APIs: Open-Meteo (Live Weather), Web Speech API (Voice Recognition)

Features: Instant English/Nepali localization, Dark/Light mode toggle, unified chat interface, and dynamic category filtering.
